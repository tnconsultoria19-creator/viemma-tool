Viemma Tours reference catalogues

airlines.txt
- A broad editable starter list of airline names for autocomplete in flight records.
- Airline schedules, operational status, and names change; this list is not a live airline registry.
- If an airline is missing, users can type a custom airline name directly in the field.
- Update this file through GitHub to maintain the shared baseline list.

cape-town-hotels.txt
- A broad editable starter list of Cape Town accommodation names for autocomplete in rooming records.
- This is not guaranteed to be exhaustive or a verified live inventory. Some entries may have changed branding or location; verify property details before confirming a booking.
- If a hotel is missing, users can type a custom property name directly in the field.
- Update this file through GitHub to maintain the shared baseline list.

The frontend should load these files from /data/airlines.txt and /data/cape-town-hotels.txt. Do not duplicate these lists as hardcoded frontend arrays.
